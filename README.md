# MLT Knowledge Arena — Split Project

## Structure

- `index.html` — page structure, SEO metadata, and external library references
- `assets/css/styles.css` — all CSS extracted from the original file
- `assets/js/data.js` — study notes data and quiz seed bank
- `assets/js/app.js` — navigation, notes, quiz, multiplayer, UI and other application logic

## How to use

Keep the folder structure unchanged and upload/deploy the complete contents.

The existing external libraries (PeerJS and QRCode.js) remain referenced from their original CDN URLs.

No study-note content or quiz data was intentionally removed during the split.
